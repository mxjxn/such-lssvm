# Archived Farcaster miniapp

This directory holds a **legacy Farcaster miniapp** that duplicated an older pool-trading UI. It was maintainer-specific, depended on hard-coded deployment assumptions, and is **not maintained** in this reference repository.

Use **`apps/web`** for the generic LSSVM reference UI (explore pools, trade, create pool, my pools).

If you need a Farcaster frame or miniapp, fork `apps/web` and wire the Farcaster SDK connectors there.
